## Root cause
Stage-1 regex ≈1 ms; stage-2 ONNX classifier (deberta-v3-base, fp32) ≈60 ms single query on 2 CPU threads. INT8 quantization was tried and REJECTED (attack score collapsed 1.00→0.06).

## Planned fix (for I2 / v0.1)
